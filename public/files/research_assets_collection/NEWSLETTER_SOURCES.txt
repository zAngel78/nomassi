TECHNICAL NOTES
================================================================================

Tools used:
- Python 3.x
- Playwright (async_api)
- Chrome/Chromium browser
- HTML to PDF Chrome extension (NYU manual capture)

Important settings:
- Viewport: 1920x1080
- PDF format: Letter
- Print background: True
- Wait times: 3-15 seconds (depending on site loading speed)
- Scroll simulation: To trigger lazy-loaded content

Challenges encountered:
1. NYU: Bot detection (403 Forbidden) - solved with manual capture
2. Columbia: Slow page loading - solved with 15 second wait + scroll
3. Brandeis: Wrong source initially (CFR vs Magazine) - corrected
4. Cookie consent popups - handled manually
