## 2. Engagement Rate Calculation Formula

### 2.1 Standard Engagement Rate Formula

```
Engagement Rate = (Total Engagements / Total Followers) × 100

Where Total Engagements = Likes + Comments + Shares + Saves
```

### 2.2 Platform-Specific Calculations

#### **Instagram**
```
ER = ((Likes + Comments + Shares + Saves) / Followers) × 100
YU Instagram ER = 1.50%
```

#### **Facebook**
```
ER = ((Reactions + Comments + Shares) / Page Followers) × 100
YU Facebook ER = 0.90%
```

#### **Twitter/X**
```
ER = ((Likes + Retweets + Replies) / Followers) × 100
YU Twitter ER = 0.80%
```

#### **LinkedIn**
```
ER = ((Reactions + Comments + Shares) / Followers) × 100
YU LinkedIn ER = 1.20%
```

### 2.3 Average Engagement Rate

```
YU Average ER = (Instagram + Facebook + Twitter + LinkedIn) / 4
YU Average ER = (1.50% + 0.90% + 0.80% + 1.20%) / 4 = 1.14%
```
