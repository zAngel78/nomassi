================================================================================
NOTAS TÉCNICAS
================================================================================

Herramientas utilizadas:
- Python 3.x
- Playwright (async_api)
- Chrome/Chromium browser
- HTML to PDF Chrome extension (NYU manual capture)

Configuraciones importantes:
- Viewport: 1920x1080
- PDF format: Letter
- Print background: True
- Wait times: 3-15 seconds (depending on site loading speed)
- Scroll simulation: To trigger lazy-loaded content

Desafíos encontrados:
1. NYU: Bot detection (403 Forbidden) - solved with manual capture
2. Columbia: Slow page loading - solved with 15 second wait + scroll
3. Brandeis: Wrong source initially (CFR vs Magazine) - corrected
4. Cookie consent popups - handled manually

PROPÓSITO DEL ANÁLISIS
================================================================================

Estos newsletters/magazines fueron capturados para análisis comparativo de:
✓ Estrategias de email marketing de universidades competidoras
✓ Diseño y layout de comunicaciones con alumni
✓ Contenido editorial y storytelling
✓ Frecuencia y consistencia de publicaciones
✓ Call-to-actions y estrategias de fundraising
✓ Promoción de eventos y engagement tactics

Estos datos complementan el análisis de:
- Social media posts (Instagram, Facebook, LinkedIn)
- Digital advertising (Meta Ads, Google Ads)
- YouTube video content
- Website design and user experience
